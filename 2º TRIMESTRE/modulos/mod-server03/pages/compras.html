🎬 Sobre o QuizToon

Bem-vindo ao QuizToon! Este é um projeto desenvolvido como atividade de HTML e rotas.

O objetivo do site é testar os conhecimentos dos participantes sobre desenhos animados, utilizando um formulário interativo.

📋 Como funciona?

O quiz possui 23 perguntas de múltipla escolha. O participante deve selecionar uma alternativa para cada pergunta e, no final, clicar em "Enviar respostas".

Depois do envio, o sistema calcula automaticamente a quantidade de respostas corretas e mostra a pontuação.
